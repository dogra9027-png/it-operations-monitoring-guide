
# Monitoring Dashboard

## Purpose

The monitoring dashboard provides an overview of monitored systems and active alerts.

## Access the Dashboard

1. Sign in to the Nexus platform.
2. Open **Monitoring**.
3. Select **Dashboard**.
4. Review the displayed system and alert information.

## Dashboard Information

| Item | Description |
|---|---|
| Active Alerts | Alerts requiring attention |
| Severity | Priority assigned to an alert |
| Source | Affected system or component |
| Status | Current alert state |

## Note

Dashboard information depends on the monitoring configuration and the user's access permissions.
